# 碗底反弹战法（Bowl Rebound）

> 本文档是“战法文档中心”入口页。底层算法实现位于 `strategy/bowl_rebound_strategy.py`。

## 1. 形态定义

碗底反弹关注的是一种**圆弧底**形态：

- 前期价格自高位回落，形成持续阴跌
- 中期成交量逐步萎缩，出现地量地价
- 末端价格不再创新低，K 线重心缓慢抬升
- 突破颈线后第一次回踩 → 形成 B1 候选买点

整段走势的低点连线类似“碗底”形状，因此命名。

## 2. 信号要点

| 要点 | 描述 |
| --- | --- |
| 圆弧下沿 | 至少 20 根 K 线构成的平滑下行 + 走平 |
| 地量确认 | 低点附近的 5 日均量低于过去 60 日均量的 50% |
| 颈线突破 | 收盘价首次站上前期反弹高点 |
| 回踩支撑 | 突破后 3-5 日内回踩颈线不破，触发 B1 |

## 3. 与 B1 / B2 战法的关系

- 碗底是**形态前提**，B1 / B2 是**触发点**
- 若一只票最近 60 根 K 线满足碗底，且当日触发 B1，则胜率显著高于普通 B1
- 在系统中以 `BowlReboundStrategy` 独立战法存在，结果会带 `碗` 标签

## 4. 风险控制

1. 颈线突破当日若成交量 < 突破前 3 日均量的 1.5 倍 → 视为假突破
2. 回踩跌破颈线超过 3%，强制止损
3. 突破后 5 日仍未启动 → 不再追入，转入观察

## 5. 在系统中的位置

- 战法实现：`strategy/bowl_rebound_strategy.py`
- 命中结果：策略结果库中 `strategy_name = BowlReboundStrategy`
- 前端展示：策略列表标签“碗”，K 线主图通过信号箭头标注

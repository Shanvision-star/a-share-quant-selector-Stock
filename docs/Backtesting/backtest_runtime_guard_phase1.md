# 回测运行保护 Phase 1 说明

## Original

回测服务会按候选逐条读取行情并执行模拟。同一股票在一个区间内多次命中策略时，日线 CSV 与趋势指标会被重复读取和计算；长区间或单股多信号场景可能拖慢前端请求。

## Revised

当前回测模块加入三层运行保护：

1. `CachingDailyDataPortal` 按股票代码缓存日线行情，同一回测请求内同一代码只读取和计算一次。
2. `max_signals_per_code` 限制单只股票在一次回测中的最大信号数，避免单股长区间反复命中导致接口等待过久。
3. `max_candidates` 与 `max_runtime_seconds` 控制总候选数量和运行预算。预算耗尽后会停止处理剩余候选，并在结果 `runtime.warnings` 和 `summary.runtime_stopped_early` 中提示。

## Impact

前端回测页新增“运行保护”参数，并展示原始候选、实际执行、已处理、耗时和截断提示。后续扩展分钟级撮合、组合资金曲线和实盘预执行时，应继续保留这些保护边界，避免单次请求无上限占用服务线程。

# 每日全市场行情与目标股票研究

## 使用

本项目根目录运行 `Run-Daily-Agent.cmd`。入口自动使用已安装 A-share Quant 的 Python；桌面关闭时会尝试启动已安装应用连接本项目。当前配置每日北京时间 18:30 由 Codex 当前聊天的自动任务调用脚本，定时器属于 Codex，脚本本身不安装第二套定时器。任务名称「每日行情与目标股复盘」，ID `automation-3`；已启用，首次定时触发仍需下一次运行验证。

电脑、网络和 Codex 需要在运行；关机或退出 Codex 时不能承诺按时执行。恢复后可运行一次相同命令补到最近已收盘交易日。

`config/daily-agent.json` 的 `targets` 可以配置目标列表，目前为 `000717 中南股份`。目标股票若只有一条活跃跟踪则复用；存在多条时需填写 `tracking_id` 选定；没有活跃跟踪则建立观察记录。`enabled=false` 可让脚本停止写操作；也可停用 Codex 中的每日自动任务。

```powershell
.\Run-Daily-Agent.cmd
.\Run-Daily-Agent.cmd --status
# 已确认全市场更新 failed/interrupted 后才可重试；保留原失败编号。
.\Run-Daily-Agent.cmd --retry-market
```

## 执行顺序

1. 使用北京时间、15:00 收盘边界和交易日历确定目标日，休市日回到最近交易日。当前项目离线日历支持至 2026-12-31；超出有效期明确失败，需要更新交易所日历，不能按普通工作日猜测。
2. 调用既有全市场更新服务，`auto_rebuild=false`、`allow_intraday_fast=false`。只更新行情，不重新扫描所有策略；旧策略记录保留自身日期。
3. 等待实际业务完成；partial、失败、目标日回退或验证未通过，均停止后续分析。保留更新业务编号和失败原因。
4. 对每只目标股票创建 `market/model` AgentRun，以目标日及以前最多 50 根真实日线为来源。逐条验证价格范围和数值，必须读到目标日；成交额单位未核验，不提供给模型，成交量仅按原 CSV 同口径比较。
5. 价格、最近 5/20 根日线的实际起止日、区间和变化由程序计算；模型只给定性解读，若输出未经程序核验的阿拉伯数字则拒绝发布。模型成功后按目标交易日追加复盘，保留原文、来源哈希、运行版本、模型与用量。相同运行追加幂等。
6. 调用 `tracking_refresh`，只刷新目标跟踪项。关联报告必须完成且已经保存到指定复盘。保留原信号日、状态、买入价、数量、意图；已有持仓只按现有买入价更新观察收益，不登记任何成交。
7. 回读桌面共用 API，并按真实 `ashare_quant` Codex MCP 配置启动 stdio 服务，检查 `quant_daily_status`、`quant_run` 的日期、运行和复盘关联。MCP 检查失败会记录为未完成，后续重跑复用已经完成的分析。

## 追踪与恢复

- `data/daily-agent/latest.json`：最近流程状态；按交易日及目标配置另存历史记录。
- `data/web_strategy_cache.db`：全市场更新作业、AgentRun、受控操作、跟踪与观察事件。
- `data/review_library/YYYY/MM/YYYY-MM-DD.md`：可编辑复盘。
- 桌面 Agent 面板：每日任务状态、失败详情及目标报告入口。
- MCP：`quant_daily_status` 查询闭环；`quant_run` 查看证据与用量；`quant_action_get` 查看真实更新/观察终态。

脚本使用操作系统文件锁阻止同机重复运行；同交易日完成后再次执行只回读核验，不重新调用模型或追加重复复盘。任务中断后恢复已记录业务 ID。模型提交响应不确定时先匹配运行历史，无法唯一恢复时明确失败，避免盲目再次付费。已经失败的模型运行保留，不自动制造多次付费重试。

每日授权只覆盖用户指定范围，不包括交易、订单确认、外部消息发送或扩大目标列表。默认测试使用隔离库和模型桩，真实供应商验证单独记录。

实施边界与官方资料见 [实施计划](daily-market-agent-plan.md)。本次运行证据保存在 `output/daily-agent-20261023/`；安装包版本仍为 0.2.0，本次功能在已连接的原项目源码与前端构建中生效。

## 首页操作

主图左上角按名称或代码搜索全市场股票；搜索结果可直接选中，也可用「上一只／下一只」依次切换当前候选或搜索结果。原下方股票表及详情入口保留。策略候选刷新不改变用户当前选股，趋势线开关在切换时保留。首页和详情共用深紫色短期趋势实线、深金色知行多空虚线。

首页初始化检查改为线程池执行；磁盘枚举期间不占用 API 事件循环。首次真实运行和桌面截图见 [验收记录](daily-market-agent-acceptance.md)。

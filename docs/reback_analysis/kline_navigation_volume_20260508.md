# K线顺序切换与成交量显示修复记录（2026-05-08）

## 问题归因

1. 策略选股列表已经按策略分组，同一只股票可能在不同策略里重复出现。如果用户逐个查看 K 线，只靠右侧列表点击会反复跨组定位，操作成本高。
2. 成交量副图原来直接按当前序列最大成交量设置 y 轴。遇到一两根极端巨量柱时，普通成交量柱会被压到接近 0，形成“成交量异常压缩”的视觉误导。
3. 页面已经有邻近 K 线预取能力，新增顺序切换应该复用 `goToStockFromList`，这样按钮、键盘和列表点击走同一条缓存路径。

## 已实现

1. 在个股 K 线页头部加入上一只 / 下一只按钮，显示当前去重顺序位置，例如 `12/154`。
2. 支持键盘 `ArrowUp` / `ArrowDown` 顺序切换，输入框、下拉框、分时弹窗等交互区域会自动避让快捷键。
3. 新增 `getStockSequenceState`，按策略列表原顺序去重，避免 B1/B2/碗形/砖型图重叠股票导致翻页重复。
4. 新增成交量自适应缩放工具：按当前 dataZoom 可视区取成交量数据，遇到孤立极端巨量时用分位数上限保护普通柱可读性。
5. K 线图监听 `datazoom` 事件，用户拖动区间后成交量轴随当前可视区重算，不再被屏幕外历史巨量长期影响。

## 前端操作习惯推导

1. 高频查看路径应该减少鼠标移动距离：用户看图时视线集中在主图，切换按钮放在页头，比去右侧列表逐项点击更顺手。
2. 列表仍是“定位入口”，按钮和键盘是“连续浏览入口”。两者共用同一跳转函数，避免状态分叉。
3. 当前序号是必要反馈，能让用户知道自己在当日选股池里的位置，减少遗漏或重复查看。
4. 成交量图优先保证普通柱可读，极端巨量仍保留 tooltip 原始值，后续可继续加“异常量标记”或“线性/自适应切换”。

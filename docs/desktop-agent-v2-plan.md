# 桌面工作台整改与独立发行计划

基线：根仓库 afc160b，嵌套前端 73bd7d4；沿用 codex/apple-quant-workspace。需求依据：2026-10-23 用户确认全部审核意见并要求直接整改、独立 Windows 交付和重新验收。

## 范围修订

- Original：桌面依赖工作区 .venv；Codex 仅取证与保存现有报告；验收主要是自动测试和页面导航。
- Revised：内置 Python 与依赖的 Windows 应用；当前股票上下文、可追踪的 Codex 报告回存、复盘股票索引、真实本地检查、受控更新/回测/加入跟踪；退出保护与业务闭环验收。
- Reason / Impact：修复审核发现的五项问题，使 UI、工具名称和实际能力一致。扩大发行范围，保持原有数据、业务路由和人工交易边界。

## Global Constraints

- 保留原有策略、K 线、复盘、跟踪、回测、更新、设置功能，复用既有服务；不引入自动交易。
- 不覆盖用户数据、密钥、无关脏文件；新测试使用临时目录或隔离工作区。
- 新 Python 文件中文模块说明；遵循现有 Vue/TypeScript/FastAPI 模式。
- 所有写业务操作需要显式 confirmed；拒绝任意 shell、任意路径、任意 HTTP 转发。
- Agent 保留身份、版本、输入输出 schema、父运行/来源快照、失败、模型用量与审计事件。
- 新源码与文档留在功能分支；不擅自合并、推送、发布或改全局记忆。
- 默认测试不调用付费模型；真实 provider smoke 与确定性测试分开记录。
- 桌面包不得包含用户 CSV、SQLite、复盘、密钥或通知凭证；首次启动无需系统 Python。
- 对未完成/未验证的行为如实记录，不以任务受理代替任务完成。

## Task 1: Agent 与 Codex 闭环

Owned：web/backend/services/workspace_agent.py、routers/workspace_agent.py、新的相邻 Agent 服务、scripts/quant_tools.py、scripts/quant_mcp.py、对应 tests；不得编辑前端、desktop 或打包脚本。

修复保存复盘 stocks 索引，合并而不覆盖原标签与正文，重试幂等。固定工作流的本地模式真正检查来源日期、缺失评估日期和截断范围，并清楚说明自由提问不由本地规则回答；前端快捷入口将据此命名为记录检查。

增加基于已完成取证运行的 Codex 结构化分析提交接口，创建独立、可追踪的子运行：校验 schema、来源 ID、父运行与证据一致性，记录 author/provider/model/prompt_version、父 ID、来源 hash；客户端 request_id 幂等，不覆盖原运行。报告可经现有确认接口保存，并按股检索。允许 parent input mode=external 的结果在前端明确显示 Codex；具体接口与字段需在实现报告给出。

增加白名单受控操作：数据更新、回测、加入跟踪，复用现有后端服务/路由；返回真实业务 ID 和状态，审计请求与结果/失败/确认，不把提交当完成。HTTP、CLI、MCP 对齐。具备查询任务和活动任务的接口，供桌面退出保护调用。所有业务写操作未经 confirmed 拒绝；保留现有工具兼容性。限流、参数校验、幂等避免重试重复执行，错误可见。

测试：复盘保存→同股检索；本地过期/缺日期检查；Codex 分析→保存→检索→父来源追溯；错误引用/未确认/重复 request_id；三类受控操作的服务调用与真实状态契约。pytest 和 app import smoke。不要运行全市场更新、实盘、通知或真实 provider。

## Task 2: 主屏与 Agent 上下文

Owned：web/frontend。缓存压缩为状态条；当前股票、清晰 K 线、策略候选优先；Apple 白色玻璃导航与轻动效、减少动态效果支持。去掉冗余说明但保留控件名称和可访问名称；内部策略枚举转显示名，原始值保留 API。

统一主页图表选择、股票详情和 Agent 当前研究对象；请求带 code，报告单独显示运行时对象/日期，历史报告不得冒充当前对象。默认本地模式命名与任务语义对应，模型/Codex 标签明确。Agent 报告支持直接跳转对应复盘/股票/跟踪；数据写入仍确认。必要时为模型配置提供可操作入口，不输出密钥。

保持所有原有路由/表单/操作可达；1251–1700 宽度不能靠无提示隐藏选股功能腾空间。测试股票上下文切换、旧报告标识、来源/错误可见、键盘关闭焦点。运行 Vitest、vue-tsc/build；无 lint 脚本如实记录。浏览器检查 1512/1366/窄屏及实际加载后的截图。

## Task 3: 独立 Windows 应用与退出保护

Owned：desktop、scripts/run_desktop_backend.py、独立打包脚本和相关测试。内置匹配的 CPython 和依赖，打包明确白名单源码与干净默认配置，独立用户数据目录，保留选择现有工作区以复用用户数据的功能。默认安装后可直接运行且不寻找系统 Python；发布 Windows 安装包和可选便携版。

正常关闭窗口/菜单退出保留 beforeunload；未保存编辑可取消退出且后端继续服务。活动任务退出需要用户选择继续等待/取消退出/中断，默认不强退；确认退出后收尾后台进程并清理发现文件。MCP 入口使用内置解释器，提供可复制配置，不要求另装 Python。

测试：打包白名单与无凭证、内置运行时 import smoke、无系统 Python PATH 的干净用户目录启动、API 认证、原生未保存取消/放弃、活动任务保护、退出清理、升级/重启数据保留。安装包不得伪称已签名。

# 砖型图战法（Brick Pattern）

> 本文档是“战法文档中心”入口页。底层算法实现位于 `strategy/brick_pattern.py`，
> 指标计算位于 `utils/technical.py` 中的 `calculate_brick_indicators`。

## 1. 砖型图原理

砖型图把每根 K 线的收盘价与前一日收盘价的差异，转换为一根带颜色的“砖”：

- 收盘价高于前收 → 红砖（多头砖）
- 收盘价低于前收 → 绿砖（空头砖）
- 砖体高度 = `|close - prev_close|`，反映动能强弱

砖型图忽略震荡噪声，把价格连续运动浓缩成方向性更清晰的色块序列，
适合配合 B1 / B2 战法做趋势确认与止损辅助。

## 2. 信号定义

| 信号 | 含义 | 默认动作 |
| --- | --- | --- |
| 四块绿砖翻红 | 连续 4 根绿砖后首次出现红砖 | 关注 B1 反弹 |
| 四块红砖翻绿 | 连续 4 根红砖后首次出现绿砖 | 触发减仓 / 警戒止损 |
| 红砖满 4 块 | 多头惯性减弱，进入“高位风险区” | 减仓一半 |
| 绿砖满 4 块 | 空头惯性减弱，可能止跌 | 观察 B1 复合信号 |

> 与 zettaranc 项目的差异：本仓库的砖型图作为 K 线副图组件存在，
> 仅辅助决策，不会自动生成下单意图。所有 OrderIntent 仍来自 B1/B2 战法。

## 3. 在系统中的位置

- 副图渲染：`web/frontend/src/components/KlineChart.vue` 中的“砖型图”按钮
- 指标数据：`web/backend/services/kline_service.py` → `indicators.brick_value`
- 策略组合：`strategy/brick_pattern.py` 提供检测函数，可被其他战法在 `detect()`
  内调用做趋势二次确认

## 4. 实战建议

1. 砖型图只是趋势辅助，不应单独作为买卖依据
2. B1 出现时若副图同步出现“四块绿砖翻红”，胜率更高
3. B2 持仓期间若副图先出现“红砖满 4 块”，建议主动减仓
4. 切勿在震荡市使用砖型图做反向交易，会被反复假信号扫损
